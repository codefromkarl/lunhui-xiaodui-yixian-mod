# 纯水试点实现与验证方案

## 产品规则

保留原36个混系商品包和144张原卡。五行新增按元素浏览已拥有卡牌、逐张选入抽牌池；初期只有水系开放单卡购买，其他元素可从已购混系包取得后自由混搭。购买不自动换池，保存不消耗点数、不替换当前手牌；原卡包选法继续可用。单卡拥有关系由原包或新单卡购买任一满足，无需为已拥有卡重复付费。

水牌按原境界开放：炼气2、筑基1、金丹2、元婴2、化神3，累计2/3/5/7/10张。炼气两张由原入宗赠包取得；单卡价格筑基15、金丹每张15、元婴每张25、化神每张25，整条路线最多170点。水火镇印赠包已含波澜，走该赠包路径最多155点。原突破与赠包保持不变，仙命另计。不强制补买另一原卡包，不改原卡效果与费用。

自由选牌为不同已购五行卡，最多16张；境界最低不同卡数2/3/4/6/8，纯水推荐为本境界全部已拥有水牌。升级和购买保留既有选择；旧小池可原样保存恢复，下一次重新选牌按当前境界下限校验。不允许混用原包与单卡选择，避免同牌重复加权；混系可以逐卡选，也可继续用原包。选择通过原生权威命令提交，使用原生持有／激活目录保存，不使用本机临时状态代替存档。

## 成长与试验

炼气印＋涛启动，筑基波澜养势，金丹水阵与泉涌周转，元婴潜遁／腾浪续航养势，化神纳百川／乘风浪／雨纷纷成长与兑现。优先固定“全部合法水牌”验证，不按种子删牌，不改卡值、策略或额外赠气。

固定91001–91004、原两策略、4回合、24张预算、属性请求10与1、原仙命敏感性。先重放当前混系对照，再使用同种子分别测试原七包水牌获取方案和新纯水单卡方案。每次赠包保留固定索引，同时补交叉赠包验证。分别报告输出、实际组装支出、累计支出、回气溢出、缺气、续牌、出牌截断和元素激活；纯水无木条件，不能冒充雨纷纷双条件收益。达到出牌上限即视为资源循环待处理，不能用被截断的数字宣称通过。

工程覆盖权威购买／重复购买／原包衍生持有、跨境界／跨门派与重复拒绝、两种选法切换、保存恢复、真实UI暂存确认及当前手牌不变。原混系同池轨迹应保持一致。只安装独立测试副本，原游戏安装不热替换。

## 首轮实机后追加的成长候选

不带专精的纯水全牌池主矩阵回气优先输出为329.25/216.75/211.5/214.75/441.75；说明购买／选牌自由本身不足以消除辅助牌稀释。记录该失败基线，追加一个固定机制候选：筑基起，开战完整纯水池获得水势结算×2的专精，不改变水牌印刷值、费用、回气或抽牌。它给积累水势明确回报，混系水势保持原值。战斗中改成混池或使用非水五行牌后，本场专精失效，切回纯水不重新获得。旧混池中保留的非水手牌会取消专精，防止通过临时切池叠加两边收益。该候选看过首轮四种子结果后提出，仍属于探索；后续同种子复跑不称为独立留出检验。
