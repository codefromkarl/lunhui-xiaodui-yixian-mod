# 云灵剑宗：先选路线，再配抽牌池

在战斗界面打开**卡包管理 → 推荐构筑**，选择一条路线，点击**套用到待选**。返回卡包页核对后，点击**保存激活选择**才会生效；取消会放弃本次待选。套用不会购买卡包，不会替换当前手牌。

推荐根据当前境界和已购包生成，未拥有核心包时明确显示过渡配置与待购包。灵剑到元婴解锁专属包后成型，前期使用云剑与回气过渡。推荐不是额外能力，也不强制绑定角色成长。

## 三条路线怎样玩

### 云剑连招：把连续出牌变成优势

优先连云，再决定什么时候插入非云剑。云剑·飞刺提供连云伤害，回守提供续航；元婴闪风与灵海提供摸牌、回气，化神游龙和追风继续运转。没有云海连绵时，非云剑会断连；有该仙命后，仍要比较当前每张牌的资源与手牌收益。

- 筑基优先补云剑灵气，金丹补云剑续势。
- 元婴购买云剑主题包；化神把最新云剑包纳入配置。
- 仙命方向：云之道、云海连绵。保留已有40点获取与效果，不强制购买。
- 决策：先出哪张建立连云、何时取回气、是否为了爆发插入剑意牌。

### 剑意／剑阵：准备后再兑现

剑挡、凝意诀积累剑意，攻击剑招整张消耗、逐段获得收益。三峰剑等多段是兑现手段；后期剑意激荡扩大蓄势，水月、御空与连环剑阵维护防守，千刃利用护盾爆发。

- 筑基优先蓄意剑阵，金丹优先多段攻守。
- 元婴、化神优先剑意剑阵主题包。
- 仙命方向：剑韵修炼、剑阵守护。
- 决策：当前剑意是否值得立刻消耗、哪张攻击最适合兑现、护盾要用来保命还是转化伤害。
- 狂剑暂是筋肉支线，不把少数狂剑牌标为已经完成的第四套构筑。

### 灵剑周转：斗气也是需要保留的资源

巨鹏是金丹过渡；元婴的百鸟灵剑诀降低灵剑附加费用，白鹭奖励保留灵气，巨象多段与加攻提供输出。化神飞灵按实际击伤回气，迅影积意续牌，万法归灵剑消耗剩余斗气收束。

- 金丹用云剑续势和低阶回气包过渡。
- 元婴购买灵剑包；化神加入灵剑包，保留元婴灵剑及金丹过渡包。
- 仙命按实际配牌选择，不以四项全购为构筑前提。
- 决策：回气是否超过池子上限、先维持运转还是直接耗尽斗气爆发。

## 池子统计怎样看

每次摸牌从启用包合并的池子里等概率抽取，抽到后不移除该牌。云剑比例是每次抽牌抽到云剑的占比，不是下一手必定连云的概率。回气／摸牌表示含对应效果的牌数，包含条件触发，不代表每次一定回气或摸牌。

新购包不再全部自动启用。纯门派配置保持原有顺序；若不足原生最低数量，只补齐到`min(3,已购包数)`。旧局现有配置不清空。原生BL08和与BL08混合的原生管理路径保持，推荐页仅针对纯剑宗。

## 本轮不改变的规则

剑宗冻结48张牌、12包、四项仙命；不调整伤害公式和仙命效果。保留最新单卡费用契约：无基础斗气费，灵气费用×4，减费最低0；首回合3张，主动摸牌1行动力，再动每次摸1张。没有增加仙命槽位、固定牌序或单卡删减系统。
