# 剑宗属性：普通剑招走筋肉／反应，灵剑走能量

状态：2026-10-22手动开关修复已通过隔离实机并安装到本机正式游戏。这里描述卡牌关联与新增修行能力，不是三派整套血统成长表的重做。

## 按路线加点

| 效果 | 属性 |
|---|---|
| 非灵剑单段攻击、连云追加伤害、震雷击伤追加伤害 | 筋肉 |
| 非灵剑多段攻击，包括三峰、流云乱剑、裂空、游龙、凌波、千刃与引气条件双段 | 反应 |
| 普通护盾、持续补盾与通用回气 | 筋肉 |
| 治疗、反身剑的延迟护盾 | 体质，保持原关联 |
| 九张灵剑路线牌的既有属性成长 | 能量 |

灵剑路线九张为：巨鹏灵剑、巨鲲灵剑、白鹭灵剑、百鸟灵剑诀、巨象灵剑、飞灵闪影剑、万法归灵剑、迅影飞剑、剑影流光。飞灵与迅影原先取反应，现在改取能量；没有属性成长项的牌不凭空增加倍率。此分类不改变原有`spirit`标签的减费范围，也不调整卡包成员。

例子：探云为`18＋80%筋肉`；裂空每段`9＋70%反应`、两段；飞灵每段`3＋40%能量`、四段；迅影为`12＋160%能量`。各牌原基础量、倍率、费用、段数、连云／剑意、击伤、范围及身份保持；本轮只变更33张牌的45处属性引用，其他已符合定位的引用不重复修改。

## 灵剑转化：20奖励点，实际扣除原属性

在主神空间的**云灵剑宗 → 专属能力**购买「灵剑转化」。炼气开放，自选购买20点，本局只收费一次，购买后默认关闭，不占手牌；是额外修行能力，不冒充原作仙命，不挤掉原有四项仙命。

购买后，在同一能力详情点击**开启转化／关闭转化**。当前状态会显示在按钮旁；切换免费、保存到本局，只有主神空间可操作，战斗中不能切换。没有开关记录的已购旧局默认关闭，不重新收费；未购买者和刚入宗的新局不发生转化。

开启时，对未转化的持久属性分别计算：

```
扣除筋肉 = floor(筋肉 × 60%)
扣除反应 = floor(反应 × 60%)
扣除体质 = floor(体质 × 60%)
新增能量 = 上述三项实际扣除量之和
```

原有能量保留。50筋肉／30反应／20体质／10能量转为20／12／8／70；7／9／11／13转为3／4／5／28。每项各自取整，能量增加量等于实际损失总和，不先把三项相加再取整。

**这是转修而非额外收益。** 转化后普通剑招、护盾、治疗、生命与暴击可能下降，灵剑伤害和斗气容量得到支持。原生派生规则按转化后的四属性重新计算生命、资源、防御、暴击和护盾效率；购买不补满扩大的资源池。关闭后恢复完整的未转化属性，购买费用不返还；切换不补满生命或气池。

出生、购买加点、血统／装备等持久来源保留原值，只在派生计算中投影转化；开启期间之后的持久加点会重新按完整来源计算，不累计扣除。比如开启能力后再加10筋肉，最终净增4筋肉与6能量，不用重新购买能力；直接加能量不扣减。正式加点后立即同步玩家实际属性与购买回执，不仅更新预览。战斗临时属性不参与转化。保存记录原生能力持有、原有属性来源及按玩家隔离的原生选择状态，恢复和反复查看不会再扣一遍。
