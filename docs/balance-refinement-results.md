# 水木化神与五行筑基第二轮结果

2026-10-20。在第一轮结果基础上，仅调整推荐选包：**水木化神输出改善，水木／土灵筑基总体回落收窄，两种赠包路径的购包成本均不增加；水火赠包的个别成长问题仍保留。** 不改卡牌数值、原卡费用、卡包价格、赠包或抽牌规则，不添加第四包。

## 最终改动

- 水木化神沿用元婴的 `五灵印法＋水木潜行＋灵根初成`，暂缓购买／启用生生流转。保留木、水印记、水木增益和多段攻击，复用灵根初成的直接攻击；仍可自由换包。
- 水木／土灵筑基沿用实际领取的赠包。不再统一提示另一包：领金木炼形就用金木炼形，领水火镇印就保留水火镇印；已有两包时优先金木炼形。金丹及元婴建议保持不变，避免把回落移到金丹。
- 推荐按境界覆盖少量优先项，筑基判断真实持有情况。仍只暂存待选包，原生确认后生效；不会自动购买或将未购包塞入卡池。
- 测试配置、目录成本审计同步识别境界优先项和实际赠包，逐条核对生产推荐。第一轮 `balance-adjusted-*` 输入保留旧固定选包，关闭新生产方法绑定；当前默认输入为 `balance-refined-*`。

方案及追加候选的理由见 [验证方案](balance-refinement-plan.md)。

### 不能被均值掩盖的残留

- 主矩阵按赠包拆组后，水火镇印路径（91002、91004）的回气优先均值仍为炼气210→筑基155.5，约 **−26.0%**。这条路径未换池，底层输出问题未修复；金木赠包两种子改善带来总体增长。低属性请求该子组为197→155.5，未越25%线，但仍有下降。新增自动报告保留赠包子组标记；主矩阵的“所有赠包路径回落均消除”验收明确为 false。
- 主矩阵水木化神种子91001，回气优先无仙命 `558→437`、有仙命 `648→607`，仍有退化；低属性对应 `531→402`、`621→565`。其余变更逐行无输出退化，手牌顺序策略的四种子均改善。配对文件保留全部种子，不能宣称每局都增强。
- 同一赠包仅绑定两个种子，未全交叉所有赠包与种子，不能据此把子组差异完全归因于赠包。筑基推荐现在复用免费赠包，解决的是不必要补买和总体节奏，没有免费改变水火牌的防御／回复定位。
- 水木化神出牌数由17.75降至15，但伤害更高；生生流转中的恢复、增益和敏捷续牌减少。静止敌人不能评价失去这些效果后的生存取舍。高阶新包暂缓购入也意味着高阶新牌体验仍需实玩验证。
