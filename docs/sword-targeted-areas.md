# 剑宗四牌：贯穿、溅射、横排与邻接范围

本轮只修改飞刺、震雷剑、无锋、镜花剑阵。卡牌身份、卡包成员、价格、原有主目标公式、灵气费用和仙命不变；不扩展其余六张候选，不添加全派通用溅射或自动护盾。

## 四张牌如何使用

| 卡牌 | 新增效果 | 原有条件仍然生效 |
|---|---|---|
| 云剑·飞刺 | 连云时，沿施法者朝目标方向贯穿后方最近一名敌人，每段50%伤害 | 非连云仍只攻击主目标 |
| 震雷剑 | 主目标实际击伤后，原有追加雷击向1格邻近最多两名敌人扩散，各承受追加伤害的40% | 只损伤护盾不触发；按追加雷击而非整张牌伤害计算 |
| 云剑·无锋 | 连云时横扫同阵位，主目标全额，其他目标每段50% | 未连云不攻击，原有付费规则不变 |
| 镜花剑阵 | 保留主目标攻击与护盾，在主目标1格邻接范围内追加30%攻击 | 次目标独立命中和防御；不以中心目标先击伤为前提 |

比例逐段向下取整。范围内不存在其他敌人时不会补成全屏或随机目标。横排属于游戏的同阵位选区，不把屏幕上的水平像素线当作战斗规则。

## 结算不能复制资源奖励

- 同张牌先快照剑意、加攻与护盾增伤；剑意只消费一次，出牌／连云／攻击计数不按目标数增加。
- 主目标保留原攻击。横排、贯穿和镜花次目标分别走原生攻击，每个目标正常判定命中、防御、护盾与本次攻击穿透；贯穿范围本身不提供无视防御或穿盾。
- 震雷在伤害钩子中检查本张牌的主目标直接攻击是否损失生命；提交一次守卫标记后，追加雷击及扩散走物理非攻击伤害，不递归触发。
- 飞牙返还剑意、游龙摸牌、飞灵逐段回气等既有击伤奖励只读取主目标直接攻击记录，不由次目标复制。
- 震雷的潜在扩散目标在出牌计划中确定；主目标被击杀不会让余波错误改选中心。结算完成清理临时目标状态。
- 连环剑阵重施镜花时保留镜花选区，不额外消费一次剑意或把范围退回全屏。

## 普通战斗采用阵位槽位，战术地图采用真实坐标

普通战斗没有原生持久列号。本Mod新增的是确定性的**阵位槽位几何**，不是读取角色动画、相机或屏幕坐标：

- 复用原生 `BattleSpawnCoordinator` 的同侧／同阵位分组与单位顺序，保留倒地单位所占槽位。
- 复用原生超过3人时分两列、沿纵向均匀分布的排列方式，将槽位归一化到阵位距离。该距离模型不等同于场景锚点的世界坐标。
- 前中后阵位间距为1格，同阵位槽位纵向总跨度为2格；拥挤分列偏移为0.208格。
- 贯穿沿施法者到主目标的射线向后选取，半宽0.25格；候选按离主目标距离排序，ID只用于同距离时稳定决胜，不按列表任取下一个敌人。
- 邻接／溅射使用曼哈顿距离不超过1格，斜对角不纳入。它是范围距离，不保证每个阵位中的任何两人都互相邻接。

行军直接读取 `MarchState` 的坐标；塔防读取 `TowerDefenseState.TryGetTileOf` 和地图格位。范围免疫目标、友方、倒地单位和辅助目标不进入次目标集合。

`SwordTargeting` 同时接收原生Mod上下文与只读UI战斗快照，使用同一选择函数。原生 `CreateModContext` 补丁以弱引用附加一次不可变位置投影，不保存静态战斗计数或权威对象。

## 预览与测试入口

四张牌的原生选中／拖动确认流程保持不变。`SwordAreaPreview` 只替换受影响目标圈集合，读取当前HUD快照，并沿用原生主目标守卫／嘲讽预告。震雷显示的是满足击伤条件时的潜在扩散范围，不表示必然造成伤害。次目标不伪造精确数值预告。

```bash
python3 scripts/build_content.py
~/.dotnet/dotnet build src/YixianSect.csproj -c Release
~/.dotnet/dotnet run --project scripts/yixian-tests -c Release -- --sword-areas
```

离线专项覆盖连云门槛、云海连绵、最近贯穿目标、同阵位、邻接与斜角、敌我／倒地／辅助／范围免疫隔离、主目标直接击伤、护盾不触发、扩散不递归、快照与执行选择一致、重施、费用与原公式。

真实Mono全套新增 `sword_four_targeted_areas`：在私有内存局中布置阵位，执行四张牌正式命令，核对实际损血目标、快照选区与一次出牌计数。该用例不绑定用户局；代码写入和编译并不代表它已经运行，也不代表鼠标、目标圈和VFX已完成画面验收。当前结果与整包依赖见[测试状态](testing-status.md)。
