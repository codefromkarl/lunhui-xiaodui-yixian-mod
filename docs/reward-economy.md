# 血统价格对齐原生，卡包与仙命保留降价

云灵剑宗、五行道盟、七星阁的五阶血统价格采用游戏原生血统的15／55／130／240／380点，合计820点。此前血统降价至10／30／65／120／190点的方案已撤回；卡包降价和仙命每项20点保持。

本轮直接读取本地游戏`ReincarnationSquad_Data/sharedassets0.assets`，15种原生血统（吸血鬼、道士、卡牌召唤者等）均采用同一组五阶价格。原始读取结果在`logs/lineage-price-alignment/research/native-catalog.json`；真实Mono测试还会比较运行时加载的15种原生血统，不以Mod自己的期望值代替原生参照。

## 只调整血统奖励点，不改战斗和存档

不改卡牌斗气／行动力费用、属性公式、段数、卡池身份、包成员或赠送资格，也不修改宿主原生血统／全局属性购买／装备的价格。不修改存档、已购记录或奖励点余额，不追缴此前降价期间少付的奖励点；后续购买按当前价格计费。

权威来源：`data/sword/lineages.json`的五阶价格同时作为其他两派的结构模板；`data/sword/{cardtable,abilities,fates}.json`与五行／七星`school.json`保存各自卡包和仙命价格。原生商店和购买命令读取同一份声明价格。独立经济期望在`tests/fixtures/reward-prices.json`，历史规则夹具不改写；保留契约只对奖励点价格做明确例外，战斗费用和数值仍精确比较。
