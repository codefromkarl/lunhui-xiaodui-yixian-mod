# 三派血统采用原生量级，按各派属性需求分配

三派五阶属性总预算为 **8／18／44／84／132**，对应炼气／筑基／金丹／元婴／化神。每阶是当前境界的完整加成，升级替换前一阶，不把五阶相加。出生、装备、属性购买和其他血统另按原生规则计算。

基准来自2026-10-22直接读取本地《轮回小队 Demo》`sharedassets0.assets`的15种原生血统：道士、斗者、吸血鬼、幻想者、正统气功使用上述总预算；原生其他血统有不同预算与机制。此次统一基础预算，保留三派卡牌与仙命的差异。

## 五行：自动主属性加辅助，不让异系路线缺气

| 境界 | 自动主属性 | 辅助属性 | 总预算 | 气池基础值 |
|---|---:|---:|---:|---:|

主能量时辅助体质；主反应或体质时辅助能量。比较主属性时同时排除五行主辅成长，仍取能量／反应／体质最高项，同为最高保留此前主项，开战后锁定。预览不累计成长、不改持有记录、不补满资源；保留主副血统与原生气池规则。没有额外生命百分比。

总预算和主项在`data/five-elements/school.json.definition.cultivation`，辅助为两者差值；静态气池等项在同一`definition.lineageStats`，不从剑宗继承。牌面双属性／70%保底公式和固定卡牌效果不变。

## 气池按原生公式计算，不把基础值当最终上限

三派使用斗气：`实际上限＝气池基础值＋2×最终能量＋最终筋肉`。例如四项出生属性均为5、无装备／其他加成时：

| 化神路线 | 实际斗气上限 |
|---|---:|
| 剑宗，未开灵剑转化 | 159 |
| 七星 | 237 |
| 五行主能量 | 245 |
| 五行主反应／体质 | 141 |

不同路线不强行做成同一气池。五行反应／体质路线由40点辅助能量支撑容量，未额外增加资源补偿公式。实际玩家还会受装备、购买属性、其他血统及转化影响。
