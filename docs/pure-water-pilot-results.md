# 纯水试点：元素购买、自由选牌与成长验证

2026-10-20至21完成实现和独立副本验证。纯水可以从炼气连续玩到化神；原混系卡包和推荐仍可用。此版本是可运行试点，**总体成长回落收窄，个别种子退化、早期缺气和中期回气溢出仍待处理**。

## 怎么使用

1. 加入五行道盟，原两个炼气赠包和筑基免费二选一保持不变。
2. 在五行商店购买名称以“水系单卡”开头的条目。价格和原境界门槛分别校验，条目展示该卡效果与斗气费用。
3. 在战斗的卡包管理中点击“自由选牌”。按全／金／水／木／火／土／中性筛选，逐张选择已拥有的牌；“纯水推荐”暂存全部已拥有水牌。
4. 点击原生保存确认。保存不扣奖励点、不替换当前手牌，下次摸牌使用新池。“返回整包”可继续使用原卡包或原混系建议。

其他元素本次未开放单买，已购混系包中的所有五行牌都可以逐张混选。已拥有原包的水牌在商店和选牌中显示为已拥有，重复单买会被权威命令拒绝，不扣点数。反向购买原混系包仍按整包价收费，本轮不做已购单卡的包价抵扣，也不退还旧支出。

自由选牌不允许同时加入整包和单卡，避免重复加权；每张不同牌只占一个选择，最多16张。重新保存时各境界最低不同牌数为2/3/4/6/8。升级、购买保持已有选择，旧的小池可原样存取；下一次重新选牌遵守当前境界下限。原整包模式仍遵循原3–8包规则（入宗仅有两包时例外）。

成长从印＋涛启动，波澜养势，金丹周转，元婴续航养势，到化神续牌和雨纷纷兑现。低阶基础牌继续有用，化神新牌通过逐卡加入，而非强迫整包替换。

### 新增的纯水专精

第一轮“自由选择全部水牌但无专精”仍有筑基输出回落，证明分包自由本身没有补齐成长。随后增加一个明确的门派成长候选：

**筑基起，开战时只启用水系牌，回合末水势伤害×2。** 基础水势每层3，专精后为6；它不额外回气、摸牌或提高印刷攻击数值，混系按原值结算。

开战混池不能中途切水获得专精；有专精后改成混池，或使用非水五行牌，本场失效，切回纯水不重获。既有非水手牌仍可使用，但会取消专精。此规则已通过正式换池及非水出牌检查。

这是本Mod新增成长机制，不把它描述成原作效果。原卡表144张牌与36个混包内容哈希保持不变，实验同时包含选牌和专精两个因素。

## 同种子验证

四种子91001–91004，两种策略、四回合、每回合24张预算，属性请求10与1；每个种子完整交叉两种筑基赠包，保留原仙命敏感性。不开局补气、不强制手牌。双方高耐久、敌人跳行动，结果用于输出和资源循环，不能当作胜率或完整游玩。

三组输入分别为原混包收集水牌、无专精纯水、带专精纯水：每组主／低属性各352个组合，共2,112组合。最终混系回归另跑主／低属性各672个组合，共1,344组合；合计3,456个核心验证组合、13,824回合。另保留中间版回归、18组合烟测与56组合化神旧池对照。

- 原混包→最终纯水：每套352配对，其中256组未干预对照轨迹完全一致，0意外变化。
- 无专精→有专精：每套352配对，其中272组未干预对照轨迹完全一致。相同纯水池在筑基起的变化明确标记为规则干预，不当成对照漂移。
- 最终混系→上版混系：共1,344组同池轨迹完全相同，包含剑宗、七星和五行原路线。没有用纯水增强改动混系水势。
- 所有完整组合均无命令错误、倒地、提前终局或出牌预算截断。退出回执、用户存档隔离通过。

不同赠包下纯水池通常相同，不能把复制的种子轨迹当作独立随机样本。专精候选是在观察首轮四种子后提出；复跑检验实现和方向，不是独立留出验证。

## 输出结果

四回合平均敌方生命削减，回气／机制优先，无仙命：

| 境界 | 原混包收集水牌 | 纯水，无专精 | 最终纯水 | 最终低属性请求 |
|---|---:|---:|---:|---:|
| 炼气 | 249.75 | 329.25 | 329.25 | 301.5 |
| 筑基 | 171.75 | 216.75 | 314.25 | 314.25 |
| 金丹 | 178 | 211.5 | 294.25 | 294.25 |
| 元婴 | 321.75 | 214.75 | 350.75 | 332.75 |
| 化神 | 244.75 | 441.75 | 593.5 | 574 |

最终两种策略、两套属性的纯水总体均值均无超过25%的相邻阶回落；主策略金丹相对筑基仍下降约6.4%，并非严格逐阶增伤。

与当前已优化的水木混系相比，主矩阵回气优先元婴为416.25→350.75，化神为564→593.5；化神手牌顺序则为564→548.5。纯水提供了可选路线，没有在所有境界、所有策略下压过混系。

### 化神新牌是否值得买

同样四种子、两赠包与策略，先在元婴保存七张纯水，再正式突破到化神，保持旧池不买化神牌，与十张完整纯水比较：

| 条件 | 元婴七张旧池 | 加入化神三张 |
|---|---:|---:|
| 手牌顺序，无仙命 | 400 | 548.5 |
| 回气优先，无仙命 | 400 | 593.5 |
| 回气优先，有仙命 | 429.25 | 524.75 |

新增购买费75点，回气优先均值提升48.4%。该对照通过真实的“先选池再突破”完成，没有绕过选牌下限塞入非法小池。

### 仍存在的退化

主、低属性各有18个“最终纯水低于原混包”的逐行配置，包含两赠包重复计数。例如主矩阵元婴种子91004、回气优先为261→102，种子91003为230→146；化神种子91002、手牌顺序为390→254。均值改善不能说明每局更强。

每套还保留16个按种子／赠包拆分的相邻阶段输出回落标记。机器报告以 `balance_status: needs_follow_up` 标识，配对／合法性检查通过不等于平衡完成。

化神全仙命、回气优先为524.75，低于无仙命593.5；低属性对应506.75与574。已激活条件会改变固定策略的出牌顺序，不能据此认为“买齐仙命必然更强”，也不能把此结果单独归因于某个仙命。

## 资源循环

最终主矩阵、回气优先、无仙命，每组8条配置、32个回合（两个赠包共享四种子）：

| 境界 | 缺气停止回合 | 回合结束满气 | 印刷直接回气溢出／总量 |
|---|---:|---:|---:|
| 炼气 | 8／32 | 4／32 | 54／460（11.7%） |
| 筑基 | 0／32 | 4／32 | 34／240（14.2%） |
| 金丹 | 0／32 | 26／32 | 440／640（68.8%） |
| 元婴 | 0／32 | 22／32 | 496／660（75.2%） |
| 化神 | 0／32 | 6／32 | 200／432（46.3%） |

低属性炼气缺气10／32，中期回气溢出更高。溢出只统计单卡印刷直接恢复部分，未将灵阵等所有额外来源混作精确总量。

最终无仙命组平均每局出牌14.5–16张，化神平均额外摸1张，无出牌上限截断或未清空队列。当前没有发现失控续牌循环，但不能据有限预算证明不存在所有无限循环。后续应优先验证中期回气过剩、炼气手牌缺气及元婴种子波动，结合真实敌人检查回复、防御和长战收益。

## 复跑

配置 `.env.local`，构建并在目标独立副本正常退出后安装当前候选：

```sh
source .env.local
bash scripts/check.sh
python scripts/install.py --game "$HOME/Games/ReincarnationSquadBalanceSteam" --apply
python scripts/run_water_pilot.py --arm legacy
python scripts/run_water_pilot.py --arm plain
python scripts/run_water_pilot.py --arm pilot
# 上三条分别再加 --low 可复跑低属性请求
python scripts/run_water_pilot.py --arm carryover
```

`plain` 临时将独立副本的专精倍数设为1，退出或失败后恢复原配置字节；不改正式安装。`legacy` 使用固定混包输入，`pilot` 使用生产纯水选择与专精。每次启动打印独立证据目录。

```sh
python scripts/water_pilot_report.py --before <legacy>/balance-results.json --plain <plain>/balance-results.json --after <pilot>/balance-results.json --out logs/water-pilot/replay-comparison.json
```

公开输入为 `data/water-pilot-{before,after}-{main,low}.json` 与 `data/water-pilot-carryover-main.json`，产品配置为 `data/five-water-pilot.json`。本机原始证据、配对、源码与DLL哈希见 `logs/water-pilot/` 和 `evidence-manifest.json`；原始游戏报告被Git忽略。
