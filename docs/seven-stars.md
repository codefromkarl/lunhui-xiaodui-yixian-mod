# 七星阁：卦雷、星位多段、后招治疗

当前七星阁为五境界 **40张牌、10个四张包、4个独立仙命**，每境界两个包。保留《弈仙牌》的原名、真实境界、归档一级原文、卡图及卡面费用；队伍治疗、分段选敌、返卦与治疗量成长按本Mod规则适配。权威输入为`data/seven-stars/school.json`，选牌历史在`data/sources/original-correction/star-selection.json`。

## 星位、星力、卦象与后招

- **星力常驻。** 处于星位时，每点星力使本派每次攻击+3，多段逐段生效，追加攻击也生效。只有星弈·尖的偶数格明确将最多2星力转为护体。
- **虚拟八格星位。** 本场成功出牌循环映射1～8格，默认3、6格是星位，第9张回1格。其他血统卡推进格位；抽牌、移动、普攻不推进。布位标记本场保留，已有星位返还4斗气。天元心法使全部八格成为星位。
- **卦象逐次确保范围／概率效果最优。** 每次独立判定消耗1点，不推进该次效果随机数；多段逐次消耗。随机治疗选人和雷击选敌独立使用原生权威RNG，不消耗卦象；气疗术、气吞山河由玩家指定治疗对象，不进行选人随机。
- **后招按同源牌次数。** 本场同一原牌`sourceId`第二次及以后使用时触发，跨回合保留。梅开二度只重施下一张七星牌一次，不再次付费或推进格位，第二次结算可以触发后招。
- **持续牌本场限用一次。** 付费前与抽池准入拒绝已生效的同源持续牌；handler也防重复。再次行动适配为额外摸一张，不增加行动力，手牌最多10张。

星位和资源只在战斗开始清理，不在大回合切换时清理。星力／卦象存储上限9999是Mod边界，不是原作上限。护体最多32个独立单层实例，满层不再增加，转化仍消费星力；普通原生攻击沿SDK扣盾前拦截，既有非攻伤／直接损血桥在实际掉血前消费护体。

## 两仪阵：群体护盾与治疗

0斗气，自身恢复`8＋20%×能量`斗气。以本次结算的卦象数量Q计算：**全体存活己方角色各获得3Q护盾、产生3Q治疗量**，包含施法者，不包含敌人、倒地角色或辅助目标，不消耗卦象。回气仍只给施法者。

例如4名存活角色、4卦象，每人获得12护盾与12治疗量，合计48治疗量；即使全员满血，仍计入48。零卦象时不产生护盾或治疗量。若静气心法已生效，实际回气产生的治疗另行结算和计数。

## 御雷卦诀与多目标雷击

御雷先攻击，再**每次固定获得卦象：金丹1、元婴2、化神3**。不依赖历史消费；零卦起手也获得，梅开重施逐次获得。若本次攻击消费1卦，则对应净变化为0／+1／+2。所得卦象仍可触发六爻绝阵，六爻是即时可被护盾抵消的非攻击伤害，不是内伤或持续损血。

轰雷掣电保留原有两段，优先选择不同存活非辅助敌人；五雷轰顶每次成功攻击随机选择一名存活非辅助敌人。单敌时集中。只分配原段数，不复制伤害；各段使用原生操作与目标失效处理，实际战斗中的击杀衔接仍需Mono验收。

## 治疗量包含溢出，驱动枯木逢春

除气疗术、气吞山河的手动指定治疗外，普通单体治疗优先在存活、未满血的己方角色中均匀随机选择，包含自身；**全部满血时仍随机选择一名存活己方角色治疗**。随机治疗每次重新筛选；单候选无需随机数。两仪阵直接覆盖全部存活队友。治疗选人不消耗卦象，不复活倒地者。

### 气疗术、气吞山河只改治疗对象，上限仍给自己

这两张牌使用原生单个友方目标选择，可指定一名存活己方角色，包含自己，也允许选满血角色；不自动改选其他受伤队友。气疗术随机产生治疗量，但受疗者固定为玩家所选对象；气吞山河仍仅在后招时治疗，首次只有自身增上限和摸牌。两张牌的生命上限增加始终作用于施法者，不转给选中队友。

梅开二度重施沿用本张指定对象，不重新随机或因满血换人；完整施放量（含溢出）仍计入施法者累计治疗量。费用、数值、后招和摸牌不变。星弈·长、仙命等其他治疗继续使用各自原有规则，两仪群疗不变。

- **实际恢复生命**受目标当前生命缺口限制。
- **累计治疗量**记录施法者本场提供的完整治疗施放值，包含属性后的数值及溢出；群体按每个受疗角色求和，仙命、后招和重施同样计入。
- 护盾、增加生命上限本身不算治疗量；治疗统计不改变生命上限，不把溢出变成额外生命。
- 同次计划先投影已有上限／治疗请求，再选择下一名受疗者；所有治疗沿原有生命队列提交，预览不修改输入状态。

**枯木逢春**保留原卡1灵气／4斗气费用，攻击为：

`30＋100%×能量＋3×floor(本场累计治疗量÷15)`

不消费累计量，跨回合保留、开战清零，并按施法者隔离。累计48时获得9基础增伤。当前采用原作比例换算，不额外设置上限；这是实现公式，不代表已通过长战平衡验收。

**静气心法**本场持续一次，仅监听本门牌实际恢复的斗气：每累计恢复4斗气，产生6治疗量；不足4的余数跨牌保留。满斗气不触发，其他血统／自然回合回气不纳入这条适配。

**气疗术**增加自身本场生命上限24，随后为指定队友随机产生`24～54＋50%×体质`治疗量。卦象可以保证治疗量上限，不改变玩家指定对象；上限增加本身不计入累计治疗量。
