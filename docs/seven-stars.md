# 七星阁：48张原牌的手动出牌适配

七星阁现按《弈仙牌》**真实牌名、真实境界和归档网页的1级效果**制作，含五境界48张牌、12个四张包、4个有来源的独立仙命。前版原创牌和蓄星／周天体系已撤换，不把旧原创规则改名包装成原牌。卡包名称、分包和商店开放安排是本Mod设计。

权威输入是 `data/seven-stars/school.json`；逐牌选择依据与旧内部槽位替换记录在 `data/sources/original-correction/star-selection.json`。资料来自[弈仙牌卡牌图鉴七星阁页](https://sharpobject.github.io/yxp_wiki/zh/sects/heptastar-pavilion.html)，这是资料站，不标作官方数据库，也不保证归档卡面与网页来自同一游戏版本。

## 保留原作的四个核心

- **星力常驻，不因攻击消耗。** 位于星位的七星攻击每点星力每次攻击加1原攻，在宿主中换算为3攻击；多段逐段生效，追加攻击也生效。只有原牌「星弈·尖」偶数格明确把最多2星力转成护体。
- **卦象逐次确保随机最优。** 每次范围随机取上限、概率随机必成，消耗1卦象且不推进该次随机数。轰雷掣电重复两次独立判定，五雷轰顶独立判定五次，不再沿用旧版“一张多段牌只耗一卦”的规则。
- **默认星位是3、6格，不是第3、6、9张。** 本场成功卡牌数循环映射到8格；第9张回到1格。斗转、坎卦、望星诀、众星拱月永久标记指定未来格，已是星位时回1灵气。天元心法能将8格全部变为星位。
- **后招从本场第二次使用开始。** 手动抽牌没有固定牌位实例，按同一原牌 `sourceId` 的使用次数判断，跨原生大回合保留；不是“回合第2张”。

## 适配边界写在每张牌上

| 原作条件 | 本Mod处理 |
|---|---|
| 固定8张循环牌序 | 依成功卡牌顺序投影虚拟1～8格；抽牌、移动、普攻不计数，原生卡会推进格位 |
| 星位增攻 | 作用于七星规则发出的攻击；不改其他血统伤害；不加强六爻／内伤等非攻击伤害 |
| 再次行动 | 沿用剑宗路径，额外摸1张；不自动出牌、不另加行动力，受10张手牌上限约束 |
| 梅开二度 | 仅重施下一张七星牌一次，不再次付费或推进格位；第二次效果会增加同源牌使用次数并触发后招；原生牌不消耗这次重施 |
| 原作持续牌使用后退出循环 | 公共出牌准入在付费和移除手牌前拒绝本场已经生效的同源持续牌；handler也防止重复叠加 |
| 星弈·断跳过下一牌 | 对手没有循环牌组，改为跳过目标下一次原生活动；原生控制免疫照常生效 |
| 护体逐次抵挡生命减少 | 每层使用一个独立原生单层拦截状态；一次命中只消耗一个实例。普通原生攻击沿用SDK扣盾前拦截，区别于原作只挡生命损失；本Mod非攻伤和直接减生命在实际掉血前消费护体，完全被盾吸收不消费。宿主限制32层，达到后不再增加，星力转换仍按牌面支付 |
| 命元、局外仙命收益 | 原作命元没有对应系统，不映射成生命或斗气；观星／卜卦的局外命元项明确不移植 |
| 其他血统的治疗／攻击 | 妙手回春只在本门治疗前加临时上限；折枝点穴只作用于本门攻击，不劫持所有原生动作 |

星图以星位1～8独立单层徽标显示，不把36／255这样的位掩码显示给玩家。六爻使用专门的 `NonAttackDamage` 权威请求，先扣盾、余量减生命；内伤立即生效使用 `DirectDamage`，不把True伤害枚举误当作通用生命减少。

状态写权威ModState并按actor隔离。大回合不重置虚拟牌序、星位、星力或卦象；战斗开始清本场状态。星力、卦象存储上限9999是本Mod边界，不说成原作上限。原作不依赖固定牌序就能保留的机制优先入选；未选黄雀在后、神龙摆尾、弯弓射虎、风雷涌动等需要方向／先机／邻接契约的牌，避免只换原名而改掉关键效果。

## 统一数值与费用

以归档1级原文为基础：攻、防、生命×3；灵气×4。单段攻击另加100%能量，多段另加40%反应，基础盾另加70%能量，基础治疗另加50%体质，基础回气另加20%能量。星力、固定返还、阵法等特殊资源收益不二次叠属性。条件追加攻击以详情中的独立攻击为准，不错误乘到原牌每段。

所有牌0行动力、**无基础斗气费**。原卡灵气费用来自 `data/sources/original-correction/original-costs.json` 和 `card-images/<sourceId>.webp` 左上角，支付 `rules.cost × 4` 斗气；每牌保留 `costEvidence`。

**已知图文版本差异：星弈·连。** 原图是4攻、灵气+1，归档网页1级正文是1攻、灵气+2。本Mod使用网页正文效果、卡面快照费用；`sourceDiscrepancies` 保留两者，不能合称“最新游戏版本”。

## 身份与验收

本版内容身份仅用 `yixian.sect.*`，与旧ID存档不兼容；不恢复旧ID迁移层，也不伪造原生BL08。旧内部key仅保留为不可见的资源槽位，不代表旧原创牌与原牌同源。一个角色最多选择一个弈仙门派，可搭配原生血统。

`StarExpansionTests()` 检查48张原牌的名字、1级原文、境界、来源链接、原卡面费用；并检查虚拟格位、常驻星力、多段与额外攻击、逐次卦象RNG、同源第二次后招、重施、持续准入、精确生命上限请求、状态隔离、序列化及四仙命。

统一生成、编译和共享测试由主代理执行并保留结果。真实Mono验收还需要实际购买／出牌／持久状态、护体单次及多段逐层消费、最大生命与治疗顺序、预览不消费状态，以及原卡图和技能面板。未获得实机证据前，不把这些项写成已通过。
