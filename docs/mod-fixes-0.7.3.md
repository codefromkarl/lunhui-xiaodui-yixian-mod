## 安装方式

首次安装和更新共用一个完整包，内含玩法与外观两个独立可启用的组件。Windows运行 `安装.bat`，Mac运行 `安装.command`，选择含 `ReincarnationSquad.exe` 的目录；也可备份旧目录后手动放入 `Mods/`。

开发入口统一为 `python3 scripts/install.py --all --apply`；外观旧入口只转发。两个包统一使用 `runtime_package.py` 解析运行依赖。安装前完整备份，暂存和回读成功后才完成替换；任一组件失败，两个组件都回滚。保留游戏的启用名单、作者代码许可和存档，由用户在原生管理界面确认启用。游戏运行中拒绝安装。

当前本地候选共有354个文件，实际运行依赖242个（玩法201、外观41）。历史图集布局、未引用图片、PDB、提示词、旧测试结果和源码不会进入安装后的Mod目录。参考来源与提示词移到完整包的 `sources/`，源码和完整旧包备份保留。历史无图更新脚本仅用于重现旧发行，不再作为玩家推荐入口。
