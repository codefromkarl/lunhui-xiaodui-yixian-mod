# 弈仙牌 · 三门派角色外观 v0.7.3

在角色创建的「信息」页点击「造型」，按门派选择角色。本包提供18位默认造型，每个角色的选择独立保存和同步；启用Mod不会自动覆盖原生角色或所有玩家，也不改变门派玩法和角色数值。

v0.7.3 修正左右手手型与拇指方向：交换手部素材与原生左右手槽的对应，保留持物侧、肩肘骨骼与动画；镜像随整个人物翻转。陆剑心两只白蓝金边靴统一缩小，并保持裤腿、踝点和地面绑定。

玩法与外观统一使用一个完整包，安装入口见[主README](../README.md)。源码安装用 `python3 scripts/install.py --all --apply`；外观旧安装脚本仅转发，不再修改启用名单或代码许可。旧的 `--stage-running-update` 已移除，正常退出游戏后再更新。

## 安装和选择

1. 正常退出游戏，解压完整包；Windows运行 `安装.bat`，Mac运行 `安装.command`，选择游戏目录。安装器自动备份并替换两个Mod。
2. 在游戏Mod管理中启用「弈仙牌 · 三门派角色外观」，确认版本 **0.7.3**，按游戏提示确认代码许可。
3. 新建角色，在「信息」页点击「随机外观」右侧的 **「造型：原生自定义」**，选择门派和角色，右侧预览会更新。
4. 选「原生自定义」恢复当前草稿此前的原生部件组合；「随机外观」仍回到原生随机。完整造型下，单部件按钮显示「随造型」并停用。

已选牧逸风的0.6.0／0.6.1角色不需重建；已选0.7.0扩展造型也沿用原身份。包ID仍为 `appearance.muyifeng`，全部18个身份不变。读取这些存档时保持本包启用。本包不提供既有原生角色中途换肤；0.5全局覆盖方案创建、但没有选择身份的角色不会被强制替换。

回退时先正常退出游戏，再恢复备份的完整旧目录，不要删除存档。

## 延续的0.7.1修复

- **双脚朝向**：逐角色校正足片镜像，同时变换其锚点，修复站姿内八；移动和攻击按动画足骨检查，镜像后方向保持一致。
- **头身接合**：改用可见颈口与衣领连接点，修复悬头、断颈。衣袍拟合参考与真实衣领分开，不通过拉长整件衣服补缝。
- **手脚衔接**：修正袖口、手腕和脚踝，去除袖片／裤片中附带的重复拳头、靴子及相邻碎片。

- **头肩头像**：保留0.7.0头像补丁，按实际头像框宽高比取景；原生或空头像恢复镜头，重复刷新不累积缩放。不改变场景、创建或队伍模型。

全部20张源PNG保留，没有重画脸、服饰或改色；修复在拆件、遮罩、锚点和绑定层完成。原生受击、倒地等特效保留。

## 造型持物不随装备变化

完整造型隐藏原生装备图像，显示角色自带持物；空手、换刀、换枪或关闭原武器显示对象均不会移除它。切回原生后恢复实际装备显示。

实际装备ID、属性、技能、攻击动作和弹道不改。例如拿扇的造型装备枪时，仍执行原有射击效果。

## 角色、存档与联机

本机和远端读取各自角色的选择，不按本机席位或全局当前图集换肤。不同造型可以同屏；对象池、召唤物和敌方准入按身份隔离。联机各端应安装并启用同版本，继续遵守游戏的Mod一致性检查。旧式全局覆盖外观Mod应停用，本包不会接管其显示回调。

原生 `BirthAppearance` 的7个byte沿原生出生payload、存档和玩家快照传递，无额外网络消息：

```text

新增角色：[255, 89, 88, 门派号, 原角色序号, 1, 0]
# 门派号：云灵剑宗1、七星阁2、五行道盟3
```

完整名单与身份见 [characters.json](characters.json)。未知／损坏身份不作为扩展外观放行；原生出生、装备、数值及保存修复检查保留。渲染时仅把传给原生SPUM的临时参数替换为合法基础造型，角色原始身份不改。

## 从源码构建

需要Python 3、Pillow、.NET SDK和合法安装的游戏。仓库根目录执行：

```sh
python3 -m pip install -r requirements-dev.txt
python3 -m unittest discover -s appearance-muyifeng/tests -v
dotnet build appearance-muyifeng/src/MuyifengAppearance.csproj -c Release \
  -p:GameManaged="/游戏目录/ReincarnationSquad_Data/Managed"
```

DLL生成到 `appearance-muyifeng/mod/appearance.muyifeng/plugins/`；该Mod目录即完整运行包。游戏程序集和编译DLL不进入Git，已编译版本从Release下载。

修改拆件数据后，用 `python3 appearance-muyifeng/scripts/build_character_atlases.py --complete` 重建元数据。逐角色 `atlasOverrides` 与冻结的 `atlas-layout-v1.json` 保证重建不覆盖手工标定；生成器不修改源PNG。

需要复跑实际图形检查时，只使用已授权、已启用本Mod并登记作者许可的独立游戏副本：

```sh
python3 appearance-muyifeng/scripts/verify.py --game "/独立副本" --preflight
python3 appearance-muyifeng/scripts/verify.py --game "/独立副本"
```

验证器不会替用户启用Mod或授予代码许可，也不使用主游戏的日常Proton前缀。`--package`可指定隔离候选；`--keyposes`缩短牧逸风主录制，但仍运行17位七阶段采样。

## 素材与源码入口

角色默认造型参考社区图鉴，不称为官方发布。每角色的 `provenance.json` 和 `prompt-v1.txt` 保存参考链接及内置ImageGen提示词；仓库包含生成的像素拆件，不包含下载的原角色立绘。权利说明见 [THIRD_PARTY_ASSETS.md](../THIRD_PARTY_ASSETS.md)。

- `SkinCatalog.cs`、`ArtAtlas.cs`：逐角色独立图集、源点变换、裁切和遮罩。
- `RigBinding.cs`：关节、持物、肩背与对象复用绑定。
- `AppearanceChoices.cs`、`CreationPicker.cs`：开放注册、身份、原生保存修复与创建控件。
- `HudPortraitFraming.cs`：只调整HUD专用镜头。
- `*Verification.cs`：仅显式测试参数启用的游戏内验证。
- [EXPANSION_PLAN.md](EXPANSION_PLAN.md)：本轮实现和验收记录，历史本地路径留作追溯。
