# 弈仙门派 v0.7.0

云灵剑宗、五行道盟、七星阁各五境界48张牌、12个四张卡包、4个独立仙命；共144牌、36包、12仙命。

- 云灵剑宗：云剑、剑意剑阵、灵剑；保留现有卡包和近期修复，使用新版内容ID。
- 五行道盟：原作灵印激活、锋锐击伤、水势和五灵阵；普通相生衔接不等于永久激活。
- 七星阁：常驻星力、逐次卦象、虚拟8格星位（默认3／6）与同源第二次后招。

每派各境界包数2／2／2／3／3。入宗赠两个炼气包，筑基从两个包免费选一，之后购买。四仙命独立货架：筑基两项、金丹两项，各40奖励点，不占手牌。

每人最多一个弈仙门派，可搭配原生血统。首回合3张，主动摸牌1行动力／0斗气；出牌0行动力，只按单卡灵气费用×4斗气，无基础费，减免可至0。手牌上限10，启用包上限8。

新两派各48张真实原作牌，依据社区图鉴归档1级文本与原卡面费用，使用原卡图和8项仙命原图。单卡详情仅展示实际效果、条件、限制与费用；来源和适配记录保留在数据及开发文档。卡包分组、手动出牌环境和属性倍率属于本Mod，不声称是原作完整复刻或最新游戏版本。开发源是独立项目yixian-mod/src与data；完整规则见游戏单卡／卡包详情及项目docs/card-packs.md。旧包残留src不是开发入口。

Linux／Proton下的真实Mono全套、隔离预制体与预览回调已验证。更新前正常退出游戏，安装后重启；不热重载、不直接改写存档或许可。覆盖范围与未验项见项目docs/testing-status.md。

内容ID统一为yixian.sect.*，不提供旧ID别名或读档迁移。此版本不兼容使用旧ID的存档，请开新局；旧局继续使用对应旧版Mod。
