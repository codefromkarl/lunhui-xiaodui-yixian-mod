普通单段攻击取筋肉、多段取反应，普通护盾／回气取筋肉；治疗与延迟盾保留体质。灵剑九张牌统一能量。炼气开放20点独立被动「灵剑转化」，实际扣除筋肉／反应／体质各60%，各项向下取整，实际扣除总量转为能量；原能量保留。自选购买、本局一次、不占手牌；购买后默认关闭。在主神空间的能力详情点击「开启转化／关闭转化」免费切换，关闭恢复未转化属性，不补满生命或气池，不转化战斗临时属性。反复查看／刷新及保存恢复不累计扣除。此能力不同于原有12仙命，开启期间持续生效，新增持久属性继续按60%转化；正式加点后同步实际属性与回执。安装与发布状态以仓库测试状态为准。
